# Robo_Hand_307.io

Robo_hand_OVT

Сайт: https://4ymdok.github.io/Robo_Hand_307.io/

Проект: Роботизированная рука с URL-управлением

Реализация антропоморфной робо-руки, работающей по гибридному принципу механики (активное сжатие сервоприводами и пассивное разжатие возвратными пружинами). Управление осуществляется по Wi-Fi через параметры URL веб-страницы.

---

## ⚙️ Технические характеристики и компоненты

* **Контроллер:** ESP8266 (NodeMCU) / ESP32 с поддержкой Wi-Fi.
* **Приводы:** 5 × Цифровых сервоприводов **DS3235** (Крутящий момент до 35 кг·см, металлический редуктор).
* **Кинематика пальцев:** * **Сгибание:** Активное, за счет натяжения качалкой сервопривода металлического троса. В цепь троса установлены пружины-демпферы для ограничения максимального усилия (защита объекта и редуктора сервы от перегрузок).
* **Разгибание:** Пассивное, за счет упругих металлических пластин на тыльной стороне пальцев.
* **Суставы:** Шарнирные соединения фаланг.

---

## 🔌 Схема подключения (Пин-аут)

> ⚠️ **ВАЖНО:** Сервоприводы DS3235 потребляют большой ток (до 2-3А при пиковой нагрузке). Категорически запрещено питать их напрямую от платы ESP8266! Используйте внешний источник питания на 6V–7.4V, объединив его минус (GND) с минусом платы.

| Компонент (Палец) | Сигнальный пин ESP8266 |
| :--- | :--- |
| Большой палец | **D1** |
| Указательный палец | **D2** |
| Средний палец | **D3** |
| Безымянный палец | **D5** |
| Мизинец | **D6** |

## 💻 Управление и API сервера

Плата поднимает веб-сервер в локальной Wi-Fi сети. Управление состоянием руки (Сжата/Разжата) происходит путем отправки GET-запросов через URL-параметры.

* **Включить (Сжать кулак):** `http://<IP_АДРЕС_ПЛАТЫ>/?status=knopka_on`
* **Выключить (Расслабить/Открыть руку):** `http://<IP_АДРЕС_ПЛАТЫ>/?status=knopka_off`

### Интерфейс веб-страницы
При переходе по ссылкам страница динамически меняет свой цвет и статус (визуализация системного лога):
* `STATUS: NONE` — Стартовое состояние (сервоприводы в исходной точке).
* `STATUS: ON` — Рука успешно зафиксирована в сжатом положении (Зеленый индикатор).
* `STATUS: OFF` — Рука раскрыта, тросы ослаблены (Красный индикатор).

## 🚀 Инструкция по запуску

1. Скачайте и установите **Arduino IDE**.
2. В настройках плат добавьте поддержку **ESP8266**.
3. Установите стандартную библиотеку `<Servo.h>`.
4. В коде прошивки измените значения переменных `ssid` и `password` на данные вашей Wi-Fi точки.
5. Загрузите скетч в плату и откройте *Монитор порта (Serial Monitor)* на скорости 115200.
6. Скопируйте выведенный IP-адрес устройства и вставьте его в строку браузера вашего смартфона или ПК.
